  사이트 고장 시 / 데이터 수정 방법 (클릭)
TIP. 메뉴 추가/수정 방법 1. index.html 파일을 클릭하고, 우측 상단의 연필 아이콘(✏️)을 누릅니다.
2. 맨 아래쪽 <script> 태그 안에 있는 menuList 목록을 찾으세요.
3. 원하는 내용을 복사해서 한 줄 추가하면 자동으로 버튼이 생깁니다.
4. 우측 상단의 Commit changes 초록색 버튼을 누르면 저장됩니다.
TIP. FAQ 검색기 내용 수정하기 (코드 수정 X) 1. 코드를 건드릴 필요 없이, 연동된 구글 스프레드시트만 수정하세요.
2. 엑셀 내용을 바꾸면 홈페이지 검색 결과도 자동으로 바뀝니다.
(단, 질문/답변 데이터가 로딩되지 않을 때만 아래 방법을 사용하세요.)
수정 시 STEP 1. 수정할 파일 열기 1. 깃허브 저장소(Repository) 페이지에 접속합니다.
2. 파일 목록에서 수정하고 싶은 파일(예: timetable.html)을 클릭합니다.
3. 파일 내용이 보이면, 우측 상단에 있는 작은 연필 아이콘(Edit file)을 클릭합니다.
(이제 메모장처럼 코드를 직접 고칠 수 있는 상태가 됩니다.)
수정 시 STEP 2. AI에게 수정 요청하기 1. ChatGPT나 Gemini를 켭니다.
2. 수정하고 싶은 파일의 코드를 전체 복사(Ctrl+A, Ctrl+C)해서 채팅창에 붙여넣습니다.
3. 자연어로 요청합니다.
(예: "시간표 디자인을 좀 더 밝게 바꿔줘", "오타가 났는데 고쳐줘")
수정 시 STEP 3. 적용하기 (Commit) 1. AI가 고쳐준 코드를 깃허브 편집 화면에 덮어쓰기(붙여넣기) 합니다.
2. 화면 우측 상단의 초록색 [Commit changes...] 버튼을 누릅니다.
3. 작은 팝업창이 뜨면 다시 한 번 초록색 [Commit changes] 버튼을 누릅니다.
4. 끝! 약 1~2분 뒤에 실제 사이트에 반영됩니다.
